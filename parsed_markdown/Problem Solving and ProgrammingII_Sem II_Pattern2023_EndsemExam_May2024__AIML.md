# Q.4

# a) Identify and describe three types of inheritance supported in Java.

[5] 3 3

In Java, the three types of inheritance are:

- Single Inheritance: This is when a class inherits from one superclass. For example, a class Dog can inherit from a class Animal.
- Multiple Inheritance: This is when a class can inherit from multiple classes. However, Java does not support multiple inheritance with classes to avoid ambiguity. Instead, it can be achieved through interfaces.
- Multilevel Inheritance: This is when a class is derived from another class, which is also derived from another class. For example, a class Animal can be a superclass for Dog, and Dog can be a superclass for Bulldog.

# b) Explain the difference between compile-time polymorphism and run-time polymorphism in Java.

[5] 3 3

Compile-time polymorphism, also known as static polymorphism, occurs when the method to be executed is determined at compile time. An example is method overloading, where multiple methods have the same name but different parameters.

Run-time polymorphism, or dynamic polymorphism, occurs when the method to be executed is determined at run time. An example is method overriding, where a subclass provides a specific implementation of a method that is already defined in its superclass.

Advantages of compile-time polymorphism include better performance and type safety, while run-time polymorphism provides flexibility and the ability to implement dynamic method resolution.

# c) Can we define an interface with a static modifier?

[5] 3 3

No, we cannot define an interface with a static modifier. Interfaces in Java are inherently abstract and cannot have static methods. However, static methods can be defined in classes that implement the interface.

# d) Illustrate with an example polymorphism in Java.

[5] 3 3

Polymorphism in Java can be illustrated through method overriding. For example, if we have a superclass Animal with a method makeSound(), and subclasses Dog and Cat that override this method to provide their specific sounds, we can call makeSound() on an Animal reference that points to either a Dog or a Cat object, demonstrating polymorphism.
