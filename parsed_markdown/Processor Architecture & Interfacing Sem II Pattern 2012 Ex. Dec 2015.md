# Explain different sources of interrupts in 8051.

The 8051 microcontroller has several sources of interrupts, which can be categorized as follows:

- External Interrupts: These are triggered by external hardware signals. The 8051 has two external interrupts, INT0 and INT1.
- Timer Interrupts: The 8051 has two timers (Timer 0 and Timer 1), which can generate interrupts when they overflow.
- Serial Communication Interrupt: This interrupt is generated during serial communication events, such as the reception of a byte.
- Software Interrupts: These can be generated by executing the INT instruction in the program.

# List all SFRs of timer programming and draw and explain PCON register.

The Special Function Registers (SFRs) related to timer programming in the 8051 are:

- TMOD - Timer Mode Register
- TL0 - Timer 0 Low Byte
- TH0 - Timer 0 High Byte
- TL1 - Timer 1 Low Byte
- TH1 - Timer 1 High Byte

The PCON register (Power Control Register) is used for power management and contains the following bits:

+-------------------+
|  SMOD  |  Reserved |
+-------------------+
|  PD    |  IDLE     |
+-------------------+

# List timer/counter modes of 8051 and draw and explain mode 0 and mode 2.

The timer/counter modes of the 8051 are:

- Mode 0: 13-bit Timer/Counter
- Mode 1: 16-bit Timer/Counter
- Mode 2: 8-bit Auto-Reload Timer/Counter

Mode 0 and Mode 2 are explained below:

# Mode 0

In Mode 0, the timer operates as a 13-bit timer. The lower 8 bits are stored in TLx and the upper 5 bits are stored in the TMOD register. When the timer overflows, it generates an interrupt.

# Mode 2

In Mode 2, the timer operates as an 8-bit auto-reload timer. The TLx register is loaded with a value, and when it overflows, it automatically reloads the value from THx.
