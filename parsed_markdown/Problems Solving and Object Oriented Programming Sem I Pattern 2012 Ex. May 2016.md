# Write a note on Standard Template Library

The Standard Template Library (STL) is a powerful set of C++ template classes to provide general-purpose classes and functions with templates. It includes algorithms, iterators, and containers. The STL is designed to be efficient and flexible, allowing developers to create complex data structures and algorithms with ease.

# What are C++ stream classes for console operations?

C++ stream classes are used for input and output operations in C++. The primary classes for console operations are:

- istream: Used for input operations.
- ostream: Used for output operations.
- fstream: Used for file input and output operations.

These classes provide various functions to handle data streams, allowing for formatted and unformatted input and output.

# Explain put(), write(), getline() unformatted I/O operations.

The following are the unformatted input/output operations in C++:

- put(): This function is used to write a single character to the output stream.
- write(): This function is used to write a block of data to the output stream.
- getline(): This function is used to read a line of text from the input stream until a newline character is encountered.

# How exceptions are handled in C++?

In C++, exceptions are handled using the try, catch, and throw keywords. When an exception occurs, the program control is transferred to the catch block that matches the type of exception thrown. This allows for graceful error handling and recovery.
